title: The Cost of a Typeface
description: A note on why this site uses the system font stack, and what a web font actually buys you.
date: 2026-05-02

<!-- PLACEHOLDER -->

A web font is a purchase, even when it is free. You pay in requests, in bytes,
in a layout that settles a beat after the text arrives, and in one more thing
that can fail on a slow connection in a place you have never been. The question
is not whether the typeface is good. It is whether it is worth that.

Most of the time the honest answer is that it is not yet worth it. A personal
site with four pages and no visual identity does not become more credible in a
licensed grotesque. It becomes slightly slower and slightly more like every
other site that made the same choice.

The system stack is not a compromise here, it is the correct default. It renders
instantly, it looks native on the machine reading it, and it costs nothing. When
this site eventually has an identity worth expressing, a typeface will be part
of expressing it, and then the cost will buy something real.

Until then the interesting constraint is that everything has to work through
hierarchy, spacing, and restraint. That is a better exercise than picking a font
anyway.
